# Portfolio Project Instructions

## Coding Style
- Use functional React components exclusively
- Follow PascalCase for component names
- Use camelCase for variables and functions

## Styling
- Primary styling with Tailwind CSS utility classes
- Use responsive breakpoints (sm:, md:, lg:)
- Implement custom CSS effects in index.css for global styles
- Maintain dark theme with slate/teal color scheme

## Component Structure
- Keep components in src/ root directory
- Import all sections in App.js
- Use semantic HTML elements (section, nav, ul, li)

## Features
- Include hover animations and transitions
- Ensure accessibility with sr-only classes and proper attributes
- Support both mouse and touch interactions

## Data
- Store tech stacks and project data as component-level constants
- Use static imports for images
